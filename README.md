# Autonomous River Cleaning Robot

A robot that collects floating waste from the surface of a river, built as a 5-member team project at a hackathon.

## Problem

Rivers carry floating waste such as plastic bottles and bags. Manual cleanup is slow, costly, hard to run continuously and unsafe for workers. This project is a robot that collects that waste from the water surface, reducing human effort and risk.
